# 🔢 줄줄이 숫자

같은 색으로 이어지는 숫자, 또는 같은 숫자 다른 색으로 줄을 만들어
받침대의 타일을 먼저 다 내려놓으면 이기는 2~4명용 타일 게임이에요.
크롬북 브라우저에서 바로 해요. 설치할 것은 없어요.

**게임 주소:** https://iooi303648-bot.github.io/-/number-tiles/

## 규칙
- 타일 106장: 1~13 숫자가 빨강·파랑·노랑·검정으로 두 벌씩 + 웃는 별 2장(아무 숫자나 대신해요)
- 한 사람에게 14장씩, 시작 순서는 무작위로 정해서 모두에게 보여 줘요.
- 내 차례에는 판에 타일을 놓고 **다 놓았어요**, 놓을 게 없으면 **한 장 뽑기**.
- 맞는 줄: ① 같은 색 이어지는 숫자 3장 이상 (13 다음 1은 안 이어져요) ② 같은 숫자 다른 색 3~4장
- 판의 줄은 자유롭게 고쳐도 되지만, 판에 있던 타일을 받침대로 가져올 수는 없어요.
- **처음 낼 때(방장이 정해요)**: 30점 이상 → 내 타일로만 숫자 합 30 이상을 내야 하고, 그 전에는 판의 줄을 못 건드려요. / 제한 없음
- **한 차례 시간(방장이 정해요)**: 1분 / 2분 / 3분 / 없음. 시간이 지나면 놓던 타일은 되돌리고 한 장을 뽑아요.
- 받침대를 다 비우면 승리. 더미가 비고 모두 한 번씩 넘기면 남은 숫자 합이 가장 적은 사람이 승리(별은 30점).

## 수업에서 하는 방법
1. 아이들에게 게임 주소를 알려 줘요 (QR 코드로 칠판에 띄우면 편해요).
2. 한 명이 이름을 쓰고 **새 방 만들기**를 눌러요.
3. 같은 모둠 친구들은 첫 화면 **열려 있는 방** 목록에서 그 방의 **들어가기**를 눌러요.
4. 방장이 규칙을 고르고 **게임 시작**을 눌러요.

## 알아 두면 좋은 점
- **혼자 연습하기**: 첫 화면 아래 작은 글씨. 로봇 1~3명과 함께해요 (인터넷 없이도 돼요).
- 탭을 닫았다 다시 열어도 같은 크롬북·같은 브라우저면 원래 자리로 돌아가요.
- 누가 나가도 남은 친구들은 계속해요. 화면이 꺼진 친구 때문에 멈추면 방장이 이름 옆 **×**로 내보낼 수 있어요.
  시간 제한이 있으면 꺼진 친구 차례는 시간이 지나고 몇 초 뒤 저절로 넘어가요.
- 친구가 타일을 옮기는 동안에는 다른 사람 화면에 아무것도 안 보이고, **다 놓았어요**를 누른 순간 바뀐 판이 보여요.
- 컴퓨터를 아주 잘 아는 학생이라면 개발자 도구로 남의 타일을 엿볼 수 있어요. 수업용이라 따로 막지는 않았어요.

## Firebase
숨은 숫자 게임과 같은 Firebase를 그대로 써요 (`rooms/nt-방번호`, `rooms/nt-lobby` 자리에 저장).
그래서 Firebase 규칙은 바꿀 필요가 없어요. 혹시 "온라인에 연결하지 못했어요"가 나오면
Firebase 콘솔 → Realtime Database → **규칙** 탭이 아래와 같은지 확인해 주세요.
```json
{
  "rules": {
    "rooms": {
      "$code": { ".read": true, ".write": true }
    },
    "lobby": {
      ".read": true,
      "$code": { ".write": true }
    }
  }
}
```

## 고친 뒤에 (개발용)
- `node bump-version.mjs` → 모든 파일의 버전 표시를 바꿔요. 옛 버전을 쓰던 화면은 스스로 새로고침해요.
- `node test/sim.js 5000` → 로봇끼리 5000판을 돌려 규칙이 깨지지 않는지 검사
- `node test/e2e.js`, `node test/practice.js` → 브라우저 화면 검사 (파일 맨 위 설명 참고)

| 파일 | 하는 일 |
| --- | --- |
| `index.html`, `style.css` | 화면 |
| `app.js` | 버튼과 화면 연결, 끌어서 놓기 |
| `rules.js` | 게임 규칙 |
| `bot.js` | 연습 모드 로봇 |
| `net.js`, `firebase-config.js` | 여러 기기 연결 |
| `sound.js`, `chat-filter.js` | 효과음, 채팅 비속어 가리기 |
