# 🔢 숨은 숫자

친구의 숨은 숫자 타일을 추리해서 맞히는 2~4명용 웹 게임이에요.
크롬북 브라우저에서 바로 할 수 있어요. 설치할 것은 없어요.

## 처음 한 번만 하면 되는 준비 (약 15분)

### 1단계: 게임 주소 만들기 (GitHub Pages)
1. GitHub 저장소 페이지에서 **Settings** → 왼쪽 **Pages**를 누릅니다.
2. **Branch**에서 `main`을 고르고, 폴더는 `/ (root)`로 두고 **Save**를 누릅니다.
3. 1~2분 뒤 이 주소로 들어가면 게임이 열려요:
   `https://iooi303648-bot.github.io/-/hidden-number/`

여기까지 하면 **연습 모드**예요. 한 컴퓨터에서 탭을 여러 개 열어야 같이 할 수 있어요.

### 2단계: 여러 크롬북이 함께하게 하기 (Firebase, 무료)
1. https://console.firebase.google.com 에 구글 계정으로 들어갑니다.
2. **프로젝트 만들기** → 이름은 아무거나 씁니다 (예: `hidden-number`). 애널리틱스는 꺼도 돼요.
3. 왼쪽 메뉴 **빌드 → Realtime Database** → **데이터베이스 만들기**를 누릅니다.
   - 위치: 아무거나 (싱가포르 `asia-southeast1` 추천)
   - **테스트 모드로 시작**을 고릅니다.
4. 데이터베이스의 **규칙** 탭에 아래 내용을 붙여 넣고 **게시**를 누릅니다.
   (테스트 모드는 30일 뒤에 막히니까 꼭 바꿔 주세요.)
   ```json
   {
     "rules": {
       "rooms": {
         "$code": { ".read": true, ".write": true }
       }
     }
   }
   ```
5. 프로젝트 첫 화면에서 **웹 앱 추가(</> 모양)** → 이름을 쓰고 등록합니다.
   그러면 `const firebaseConfig = { ... }`가 나와요.
6. 이 저장소의 `hidden-number/firebase-config.js` 파일을 열고,
   `export const firebaseConfig = {};` 부분을 아까 나온 `{ ... }` 내용으로 바꿔서 저장합니다.
   `databaseURL` 줄이 꼭 있어야 해요. 없으면 Realtime Database 화면 위쪽의 주소(`https://...firebasedatabase.app`)를 넣어 주세요.

게임 첫 화면에 **🌐 온라인 모드**라고 나오면 성공이에요!

> firebase-config.js 안의 값은 공개되어도 괜찮은 값이에요. 비밀번호가 아니에요.

## 수업에서 하는 방법
1. 아이들에게 게임 주소를 알려 줍니다. QR 코드로 만들어 칠판에 띄우면 편해요.
2. 한 명이 **새 방 만들기**를 누르면 4자리 방 번호가 나와요.
3. 같은 모둠 친구들은 방 번호를 넣고 **들어가기**를 누릅니다. (한 방에 2~4명)
4. 방장이 **게임 시작**을 누릅니다.

## 알아 두면 좋은 점
- 학교에서 `github.io`나 Firebase 주소를 막아 두었다면 열리지 않아요. 전산 담당 선생님께 확인해 주세요.
- 게임 중에 한 명이 창을 닫으면, 그 친구 차례에서 게임이 멈춰요. 같은 크롬북에서 주소를 다시 열면 이어서 할 수 있어요. (같은 탭에서 새로고침해도 돼요.)
- 컴퓨터를 아주 잘 아는 학생이라면 개발자 도구로 숨은 숫자를 엿볼 수 있어요. 수업용 게임이라 따로 막지는 않았어요.
